如何修正權限問題：

您的 Firebase 資料庫預設阻擋了讀寫。請依照以下步驟開放：

  1. 進入 Firebase Console
  2. 點擊左側 Firestore Database
  3. 切換到上方 Rules (規則) 分頁
  4. 將內容修改為以下程式碼並發佈：
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
